# QA Study — Hotmart

Estudo prático de Quality Assurance realizado sobre funcionalidades
publicamente disponíveis da plataforma Hotmart.

> Este projeto tem finalidade exclusivamente educacional e busca
> demonstrar uma abordagem de testes funcionais, validação de regras
> de negócio, testes exploratórios e identificação de oportunidades
> de melhoria.

## Objetivo

Avaliar determinados fluxos da plataforma sob a perspectiva de um
usuário, identificando comportamentos inconsistentes, possíveis
defeitos e oportunidades de melhoria na experiência.

## Escopo

- Cadastro e configuração de produto
- Checkout
- Fluxo pós-compra

## Fora de escopo

- Testes de segurança invasivos
- Tentativas de exploração de vulnerabilidades
- Manipulação de transações financeiras
- Testes de carga
- Acesso a dados de terceiros

## Estratégia

- Testes funcionais
- Testes negativos
- Boundary Value Analysis
- Testes exploratórios
- Validação de regras de negócio
- Testes de persistência
- Avaliação de mensagens e feedback ao usuário
